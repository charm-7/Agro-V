

# Agro V 🌱
## AI-Powered Farming Assistant

Agro V is a smart farming application designed to help farmers and gardeners identify plant diseases and improve crop management.

## Features (Planned)

### Version 1
- Plant disease detection
- Disease information
- Treatment suggestions
- Disease history reports

### Version 2
- Weather integration
- Soil analysis
- Crop recommendations

### Version 3
- Market price tracking
- Harvest prediction
- Profit estimation

## Technologies

- Flutter (Mobile App)
- Python (AI & Machine Learning)
- TensorFlow (Disease Detection)
- OpenCV (Image Processing)
- Firebase (Database)

## Future Goals

- Tamil language support
- Voice assistant
- Offline disease detection
- Expert consultation
