🌱 AgroV - Smart Agriculture Assistant

AgroV is an AI-powered agriculture assistant designed to help farmers detect plant diseases, improve crop health, and make informed farming decisions using Artificial Intelligence and Computer Vision.

It focuses on simple, practical, and rural-friendly solutions for modern farming.

«⚠️ Project Status: This project is currently under active development. Features are being continuously improved and added.»

---

🚀 Features

🌿 Version 1.0 - Plant Health Assistant

- Plant disease detection using AI
- Disease name and confidence score
- Symptoms and treatment suggestions
- Fertilizer and prevention guidance
- Organic and natural remedies
- Disease history tracking
- Basic Tamil language support

---

🌦️ Version 2.0 - Smart Farming Tools

- Weather forecast integration
- Soil health analysis
- Crop recommendation system
- Irrigation suggestions
- Water requirement calculator
- Nearby agricultural shop locator
- Government schemes information

---
